# 🚨 异常处理

## 网络相关

如果运行中出现以下信息任一条

```text
登录失败，请检查网络连接
```

```text
[-]Connect retry X/X
```

```text
Caused by ProxyError
```

请检查网络连接，推荐按以下方式处理

* 重新打开代理软件
* 逐个更换代理节点，提供商或代理软件后重试
* 如果未开启自定义代理，请开启全局代理后再运行客户端 
* 重启路由器

## 打开客户端无任何反应

若运行 `MDC.exe` 或 `MDC.app` 后没有任何反应，请先按系统类型[清空配置](/zh-Hans/clean_config.html)，然后重新启动 MDC 客户端

## 打开客户端后，窗口内容无法显示

请按以下步骤排查

1. 确认客户端压缩包已完整解压，不要直接在压缩包内点击 exe 文件运行
2. 临时关闭杀毒软件或安全防护软件后，重新打开客户端
