# 浏览已刮削媒体

已经由 MDC 或其他刮削工具整理好的影片，不需要重新刮削，也能在 MDC 中快速查看  
打开“完成项目信息”，点击下方“浏览完成目录”，快速扫描已刮削目录，元数据会集中呈现，找片、核对信息、查看封面都更直接。

### 🔎 搜索和筛选

按文件名、标题、系列、厂商、导演、演员、类型、标签等元数据搜索，结合筛选和排序快速缩小范围，在大型媒体库中也能迅速找到目标项目。

### ⚡ 快速扫描

快速扫描由 MDC 或其他刮削工具已刮削的媒体和元数据，扫描后不生成缓存文件、不额外占用空间。


## 界面预览

### 列表视图

用熟悉的表格快速扫过整个媒体库。文件名、标题、发行日期、系列、厂商、导演、演员、类型和标签等字段一目了然，支持排序、分页和自定义显示列。

<img class="mdc-screenshot" src="/images/completed_projects_1.jpg" alt="元数据浏览列表视图">

### 封面视图

切换到封面墙，用海报快速定位影片。封面、标题和关键元数据集中展示，支持排序、调整卡片大小，并可点击进入详情。

<img class="mdc-screenshot" src="/images/completed_projects_2.jpg" alt="元数据浏览封面视图">

### 查看和编辑详情

点击项目即可查看海报、标题、标签、演员、类型、发行日期等完整元数据，并保存修改。

<img class="mdc-screenshot" src="/images/completed_projects_3.jpg" alt="元数据详情编辑界面">

### 重新刮削和自定义刮削

在列表或封面视图中右键项目，可以选择“重新刮削”或“自定义刮削”。自定义刮削支持修改搜索名称，再按新的名称查找并更新元数据。

## 从文件夹到媒体库，只需三步

1. 在客户端打开“完成项目信息”，点击“浏览完成目录”。
2. 选择包含 NFO 文件的完成目录，等待快速扫描完成。
3. 在列表视图和封面视图之间切换，搜索、筛选项目并打开详情。

::: info
元数据浏览器只读取你本地已有的文件和元数据，不提供任何影片下载途径，适合整理个人媒体库。
:::
