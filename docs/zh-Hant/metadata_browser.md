# 瀏覽已刮削媒體

已由 MDC 或其他刮削工具整理好的影片，不需要重新刮削，也能在 MDC 中快速查看。開啟「完成項目資訊」，點擊下方「瀏覽完成目錄」，快速掃描已刮削目錄，元資料會集中呈現，找片、核對資訊、查看封面都更直接。

此功能免費提供，前往[下載](https://dl.mvdc.top)取得客戶端。

### 🔎 搜尋和篩選

按檔案名稱、標題、系列、廠商、導演、演員、類型、標籤等元資料搜尋，結合篩選和排序快速縮小範圍，在大型媒體庫中也能迅速找到目標項目。

### ⚡ 快速掃描

快速掃描由 MDC 或其他刮削工具已刮削的媒體和元資料，掃描後不生成快取檔案、不額外佔用空間。

## 介面預覽

### 列表視圖

以熟悉的表格快速瀏覽整個媒體庫。檔案名稱、標題、發行日期、系列、廠商、導演、演員、類型和標籤一目了然，支援排序、分頁和自訂顯示欄位。

<img class="mdc-screenshot" src="/images/completed_projects_1.jpg" alt="元資料瀏覽列表視圖">

### 封面視圖

切換到封面牆，用海報快速定位影片。封面、標題和關鍵元資料集中展示，支援排序、調整卡片大小，並可點擊進入詳情。

<img class="mdc-screenshot" src="/images/completed_projects_2.jpg" alt="元資料瀏覽封面視圖">

### 查看和編輯詳情

點擊項目即可查看海報、標題、標籤、演員、類型、發行日期等完整元資料，並儲存修改。

<img class="mdc-screenshot" src="/images/completed_projects_3.jpg" alt="元資料詳情編輯介面">

### 重新刮削和自訂刮削

在列表或封面視圖中右鍵項目，可以選擇「重新刮削」或「自訂刮削」。自訂刮削支援修改搜尋名稱，再按新的名稱查找並更新元資料。

## 從資料夾到媒體庫，只需三步

1. 在客戶端開啟「完成項目資訊」，點擊「瀏覽完成目錄」。
2. 選擇包含 NFO 檔案的已刮削目錄，等待快速掃描完成。
3. 在列表視圖和封面視圖之間切換，搜尋、篩選項目並開啟詳情。

::: info
元資料瀏覽器只讀取你本地已有的檔案和元資料，不提供任何影片下載途徑，適合整理個人媒體庫。
:::
