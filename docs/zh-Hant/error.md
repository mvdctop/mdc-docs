# 🚨 錯誤處理

## 網路相關

如果日誌中出現以下資訊任一條

```text
[-]Connect retry X/X
```

```text
登入失敗，請檢查網絡鏈接
```

```text
Caused by ProxyError
```

請檢查網路設定，推薦按以下方式處理

* 重新啓動路由器
* 重新開啟代理軟體
* 逐個更換代理節點，提供商或代理軟體後重試
* 如果未開啟自訂代理，請開啟全域代理後再執行客戶端

## 開啟客戶端無任何反應

若執行 `MDC.exe` 或 `MDC.app` 後沒有任何反應，請先按系統類型[清空配置](/zh-Hant/clean_config.html)，然後重新啟動 MDC 客戶端

## 開啟客戶端後，視窗內容無法顯示

請按以下步驟排查

1. 確認客戶端壓縮包已完整解壓，不要直接在壓縮包內點擊 exe 檔案執行
2. 暫時關閉防毒軟體或安全防護軟體後，重新開啟客戶端
